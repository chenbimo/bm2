## 文件

`bm2.toml` 在项目目录里,一个文件配置一个项目。`bm2 check` 单独校验;`bm2 start` 也会先校验,不合法就不启动。配置不执行 shell 字符串,启动命令固定为参数数组——这是不可回退的设计。

## 顶层字段

| 字段 | 默认 | 拒绝条件 |
| --- | --- | --- |
| `name` | 必填 | 不符合 `[A-Za-z][A-Za-z0-9_]*`,或与已注册项目重名(fork 模式还要看端口) |
| `cwd` | 配置文件所在目录 | 不是绝对路径;**运行时不存在即启动失败** |
| `script` | 必填 | 含 `..` 段,或指向项目目录之外 |
| `runtime` | `bun` | 不是 `bun` / `node` |
| `exec_mode` | `cluster` | 不是 `cluster` / `fork` |
| `instances` | 必填 | 小于 1 或大于 1024 |
| `port` | 必填 | 不在 1..65535;**与任何已注册项目的端口范围重叠** |
| `max_memory_mb` | 512 | 小于 1 或大于 1048576 |
| `max_restarts` | 10 | 小于 0(0 表示首次异常即 errored,合法) |
| `restart_delay_ms` | 1000 | 小于 0 |
| `min_uptime_ms` | 10000 | 小于 0 |
| `stop_timeout_ms` | 10000 | 不在 1..60000 |

## 子表

| 表 | 字段 | 默认 | 拒绝条件 |
| --- | --- | --- | --- |
| `[logs]` | `max_size_mb` | 10 | 小于 1 或大于 102400 |
| `[logs]` | `keep` | 0 | 不在 0..1000;0 表示代数**不限** |
| `[notify]` | 见 `07-notify.md` | 关闭 | 未知键、非法目标、非法时长 |
| `[env]` | 任意合法变量名 | 空 | 键不是合法变量名,或值不是字符串 |

**未知字段一律拒绝**,包括子表里的未知键。拼错一个字段名而静默生效,比启动失败难查得多。

## 校验在解析期,不兜底

越界的值直接拒绝,不夹取、不取默认,理由要具体到字段名:

| 值 | 为什么它不是一个合法值 |
| --- | --- |
| `logs.max_size_mb = 0` | 会让日志**静默地永不轮转**;「不轮转」应当写成足够大的值,而不是 0 |
| `logs.keep` 为负 | 无意义(0 已表示不限) |
| 端口范围重叠 | 两个项目抢同一端口,后启动的一方会随机失败 |
| `cwd` 不存在 | 启动时才发现,错误信息在实例上下文里,不如在解析期说清楚 |

错误信息要点名冲突对象:端口冲突报出另一个项目的名字与它占用的范围。

## 环境变量

状态目录由 `BM2_HOME` 覆盖(默认 `$HOME/.bm2`)。运行时路径与其它可覆盖项见 `README.md` 的环境变量一节——**那里是用户面的事实,这里是解析规则**。

**环境变量值不得写入状态文件、事件、crash 日志或 CLI 输出**,`[env]` 也不例外。
